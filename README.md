# Postcard Service

Команда: vlm: ВихляевМД, ГнеушевЛА, АндреевВВ

Сервис, который превращает загруженную фотографию в готовую открытку: подгоняет под формат открытки,
добавляет рамку, подпись, фильтр и почтовый штамп. Курс «Программная инженерия».

## Какую проблему решает

Сделать открытку из фотографии в графическом редакторе долго: нужно подобрать формат, рамку и подпись.
Сервис делает это за один запрос и в одном стиле. Он работает как фоновое задание: клиент загружает фото,
получает номер задания, затем проверяет статус и забирает готовый результат.

## Для кого

- **Пользователь (клиент API):** загружает фото, выбирает оформление, забирает открытку.
- **Сторонний сервис:** автоматически генерирует открытки по API (например, поздравления из другой системы).

## Что входит в систему

- Приём изображения и списка операций через HTTP API с машиночитаемым контрактом (OpenAPI).
- Асинхронная обработка: каждое обращение становится Job с жизненным циклом `created → running → done / failed / cancelled`.
- Набор операций (Tools): подгонка под формат, рамка, подпись, фильтр, штамп. Новые операции добавляются без правки ядра.
- Подпись «Привет из <город>» по GPS из EXIF через внешний геокодер (адаптер с timeout, retry и fake для тестов).
- Хранение истории заданий в БД и результатов в файловом томе.
- Структурированные логи, health check, запуск одной командой `docker compose up`.

## Что точно не входит

- Пользовательский интерфейс (только API).
- Генерация и нейросетевая стилизация изображений: обработка детерминированная.
- Печать и физическая отправка открыток, платежи.
- Аккаунты, регистрация и авторизация пользователей.
- Ограничение частоты запросов и квоты (rate limiting) в первой версии.
- Долгое хранение фотографий: срок хранения исходников и результатов ограничен конфигурацией.

## Как устроена система

```
запрос → Job → Dispatcher → Registry → Tool → ToolResult
```

Dispatcher берёт Job, по названию операции находит Tool в Registry и выполняет операции по порядку;
Dispatcher не знает конкретных Tool. Во втором семестре перед этой схемой встанет LLM, которая по фразе
на естественном языке составит список операций.
